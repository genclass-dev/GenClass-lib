How it works

A model in the browser, deciding at the network boundary.

01

Observe

One line wraps fetch, XHR, WebSocket and EventSource, and finds React, Redux and Zustand (devtools) state.

02

Triage

Cheap facts are computed for everything; only salient situations reach the model.

03

Decide on the device

The model runs in a Web Worker and returns a diagnosis and an action, with no server call.

04

Report, or act

Observe reports with the evidence. Guard can drop a stale write or merge a duplicate, with undo.

Install

One line, first in your app.

// npm i @genclass/runtime, then first line of src/main.ts
import "@genclass/runtime/auto";          // observe: reports, changes nothing
// import "@genclass/runtime/auto/guard";   // let it act
// instrumentation-client.ts (project root)
import "@genclass/runtime/auto";
<!-- first in <head>, no build step; keep the version pinned -->
<script src="https://cdn.jsdelivr.net/npm/@genclass/runtime@0.2.1"></script>
# detects your framework, shows the diff, asks, then writes
npx @genclass/runtime init
npx @genclass/runtime init --mode guard
npx @genclass/runtime remove   # undo exactly what init added

Anonymous diagnostics, with no page text, are on by default. Turn them off with GenClass.init({ telemetry: false }) or npx @genclass/runtime init --no-telemetry. See what is sent.

FAQ

Questions

Is GenClass free?

Yes. The runtime is open source under Apache-2.0 and free, including in commercial apps, with no usage limits. GenClass Cloud and Enterprise are planned paid products for teams; they have no customers yet.

Does GenClass need an account or an API key?

No account or API key is needed to run it: one script tag or import "@genclass/runtime/auto" is all it takes, and the model runs on the device. An optional free account shows your app's detections on a dashboard at genclass.dev. The dashboard fills from deployed pages with diagnostics on, so telemetry: false leaves it empty, and runtime 0.2.2 and earlier do not send to it.

Will GenClass break my app?

The default mode only observes and changes nothing. Across 7 frameworks and 15 data layers, GenClass introduced no bugs in 3,510 test runs (runtime 0.1.0-beta.4, the code shipped as 0.2.1; model 0.2.0). Adding ?genclass=off to a URL turns it off on that page.

Where do GenClass reports go in production?

By default to the end user's browser console, which you do not see. The sinks option forwards each report to your own logging, Sentry or PostHog. Anonymous diagnostics go to the GenClass maintainers to improve the model, and to your dashboard if you have one; telemetry: false turns them off.
