Set up in a minute

  1. One package. Its only runtime dependency is onnxruntime-web. Or run npx @genclass/runtime init and let the CLI wire it in.
    Quickstart
  2. Make it the first import of your app. It wraps fetch, XHR, WebSocket and EventSource. Next.js uses instrumentation-client.ts; plain HTML takes one script tag.
    Every framework
  3. Observe mode is the default: it reports in the console and changes nothing. ?genclass=off turns it off on that page.
    API reference
  4. Switch to guard when you trust what it sees. It can drop a stale write or merge a duplicate, with undo.
    Options

Frequently asked questions

Is GenClass free?

The runtime and its on-device model are: open source under Apache-2.0 and free, including in commercial apps, with no usage limits. The genclass.dev dashboard comes with Pro ($99 a month), with 1 year of history, data export and forwarding. Get a 7-day free trial for analytics: a card is required, and it is first charged $99 when the 7 days end, unless you cancel before. Custom ($599 a month) adds a model trained on your app. See pricing.

Does GenClass need an account or an API key?

No account or API key is needed to run it: one script tag or import "@genclass/runtime/auto" is all it takes, and the model runs on the device. With Pro (get a 7-day free trial for analytics), a dashboard at genclass.dev shows your app's detections. The dashboard fills from deployed pages with diagnostics on, so telemetry: false leaves it empty, and runtime 0.2.2 and earlier do not send to it.

Will GenClass break my app?

The default mode only observes and changes nothing. Across 7 frameworks and 15 data layers, GenClass introduced no bugs in 3,510 test runs (runtime 0.1.0-beta.4, the code shipped as 0.2.1; model 0.2.0). Adding ?genclass=off to a URL turns it off on that page.

Where do GenClass reports go in production?

By default to the end user's browser console, which you do not see. The sinks option forwards each report to your own logging or to an endpoint you own. On Pro, the genclass.dev collector can also forward detections to Sentry, PostHog, Datadog, Slack or a signed webhook, with no code in your app. Anonymous diagnostics go to the GenClass maintainers to improve the model, and to your dashboard if you have one; telemetry: false turns them off.
