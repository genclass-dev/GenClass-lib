Where it is today

Precise when it acts, and it rarely acts.

GenClass is tuned to almost never be wrong when it acts. At the default setting guard acts on 7.5% of the real cases where acting would help; the eager setting reaches 21%. Each training round so far has lifted recall at the same safety level, and the main value today is in what it reports.
