Set up in a minute

  1. One package. Its only runtime dependency is onnxruntime-web. Or run npx @genclass/runtime init and let the CLI wire it in.
    Quickstart
  2. Make it the first import of your app. It patches fetch, XHR, WebSocket and EventSource. Next.js uses instrumentation-client.ts; plain HTML takes one script tag.
    Every framework
  3. Observe mode is the default: it reports in the console and changes nothing. ?genclass=off turns it off instantly.
    API reference
  4. Switch to guard when you trust what it sees. It can drop a stale write or merge a duplicate, with undo and an audit trail.
    Options

Frequently asked questions

Is GenClass free?

Yes. The runtime is open source under Apache-2.0 and free forever, including in commercial apps, with no usage limits. Cloud and Enterprise are optional paid products for dashboards, alerts, rollout controls, SSO and audit logs.

Does it need an account or an API key?

No. One script tag or import "@genclass/runtime/auto" is all it takes.

Where does the AI model run?

In your users' browsers, inside a Web Worker on WebGPU or WASM. No server, no inference fees, and it keeps working offline.

Will it break my app?

The default mode only observes. Across 7 frameworks and 15 data layers it introduced no bugs in 3,510 runs. ?genclass=off turns it off instantly.

How often does it act today?

Rarely, by design. It is tuned to almost never be wrong when it acts, so at the default setting it acts on about 8% of the cases where acting would help. The benchmarks show the exact trade-off.

What does telemetry send?

Anonymous diagnostics about GenClass's own decisions: the diagnosis, the action, confidence, latency and counts, plus the app's hostname and route. No page text by default, never cookies, headers or bodies. Turn it off with telemetry: false or ?genclass=no-telemetry. Everything it sends.

Is the demo above real?

Yes. This page loads @genclass/runtime@{{rt}} from npm and runs the model on your device. The demo calls a real API with real delays. Telemetry is off on this site.
