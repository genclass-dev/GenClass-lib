# GenClass documentation

This is the index of the GenClass Runtime documentation: which document answers which question, how current each one
is, and where genclass.dev shows it. It covers `@genclass/runtime` on `main` (version string 0.3.0-beta.0, plus the
changes the CHANGELOG lists under 0.3.0-beta.1, unreleased; `npm i @genclass/runtime@beta` installs 0.3.0-beta.0,
`npm i @genclass/runtime` installs 0.2.2) and the model `@genclass/runtime-model` 0.2.0. Items marked 0.3.0 are in
the 0.3.0 line (0.3.0-beta.0 and later) and not in 0.2.x. The [glossary](#glossary) at the end defines the terms the
other documents use.

## What is GenClass Runtime?

GenClass Runtime (`@genclass/runtime`) is an open-source (Apache-2.0) browser library that reports race conditions in
web apps while they happen: stale responses that land over newer data, duplicate requests such as double submits,
inconsistent state and failure storms. A small model runs on the user's device, in a Web Worker on WebGPU or WASM,
and each report comes with its evidence. By default it only reports (`observe`): it never holds, delays or changes a
request, a response or a state write. The opt-in `guard` mode may act on a few of them: on held-out data it acted on
7.5% of actionable real-app cases at a 0.00% false-intervention rate (7.8% of clear simulated cases at 0.13%), but in
the six demos no mode lowered the bug rate ([RESULTS.md §1](RESULTS.md#1-model-stages-compared-held-out-simulated-apps),
[§5](RESULTS.md#5-demos)). The `heal` mode is experimental.

Every measured number (recall, false-intervention rate, cost, size) is in [RESULTS.md](RESULTS.md), with the
false-intervention rate next to each recall figure.

## Glossary

- **observe**: the default mode. GenClass watches and reports what the model finds; it never holds, delays or
  changes a request, a response or a state write, and no action runs.
- **guard**: an opt-in mode. GenClass may also run guard-tier actions when the gate clears: `discard`, `defer`,
  `coalesce` and `delay`. They withhold, deduplicate or slow something down; they never invent data or fail a
  request.
- **heal**: the experimental mode. It adds the heal-tier actions `block`, `serve_cached`, `retry`, `hedge`,
  `rollback`, `resync` and plugin actions.
- **trigger**: the kind of moment at which the runtime may ask the model: `delivery` (a response or pushed message
  is about to reach the app), `mutation` (a state write), `request` (a request is about to be sent), `failure`,
  `stall`, `inconsistency` (a learned relation between fields broke), `transition` (an operation changed state
  unlike it usually does), `error`, and `ask` (a question the app asks itself with `rt.ask()` or `rt.decide()`,
  which offers no actions). Each of the other eight has its own passive action and its own set of actions
  ([API.md, Triggers and actions](API.md#triggers-and-actions)).
- **situation**: the short text the model reads at a trigger (sections `app`, `trigger`, `facts`, `in_flight`,
  `timeline`, `state`, `stats`), with two standing questions: the diagnosis and the action. Its format is frozen
  under the tag `situation-v2.3`. By default (`triage: "salient"`) only salient situations (at least one
  non-neutral fact) reach the model; the app's own `rt.ask()` and `rt.decide()` questions, and plugin questions
  marked `always`, are asked regardless.
- **diagnosis**: the model's label for a situation: `expected`, `stale`, `conflict`, `duplicate`, `inconsistent`,
  `failing`, `transient`, `slow`, `overload` or `unusual`.
- **detection (likely, possible)**: a report that something is wrong. Likely: the top diagnosis is not `expected`
  and its probability reaches the report gate of the active profile. Possible (0.3.0, observe by default): it
  reaches the `eager` profile's lower report value but not the report gate. It prints with `console.debug`, shows
  dimmed in the devtools, is counted in `summary().possibleDetections` and is sent in telemetry as a `detect` event
  with `tier: "possible"`; `detect` and `report` listeners and a `report` function get it only when the app sets
  `detect: "possible"`, and sinks only with `possible: true`.
- **gate**: the policy check before any non-passive action. It applies protected and cross-origin requests, the
  route rule an operation started under (`off` or `observe` rules block it), the mode, `allow` and `deny`, the
  diagnosis (never `expected`), the model's gate for the active profile, the action limits and the app's
  `onBeforeAction` veto ([API.md, Policy](API.md#policy)). Model 0.2.0 ships a gain gate: the estimated gain of the
  best permitted action over doing nothing must clear a margin per tier and trigger. A model without a gate of its
  own uses a summed probability of 0.9 (guard) or 0.8 (heal) at `balanced`; `cautious` adds 0.05 to both and
  `eager` subtracts 0.05.
- **profile, aggressiveness**: `cautious`, `balanced` (default) or `eager`, or a number from 0 to 1 between them.
  It selects the model's gate profile: its margins for actions and its report value for detections. The values
  are in the [model card](../../packages/runtime-model/MODEL_CARD.md).
- **FIR (false-intervention rate)**: the share of cases where doing nothing was best but the gate fired anyway.
  RESULTS.md reports it next to every recall figure.
- **false-detection rate**: the share of decisions on correct traffic that were reported as a problem.
- **recall**: for detections, the share of real problems reported with the right diagnosis. For actions, on
  simulated apps, the share of clear cases (the gold label puts at least 0.9 on one permitted action other than
  doing nothing) on which the gate acted, and on real apps the share of actionable cases on which it acted
  ([RESULTS.md §1](RESULTS.md#1-model-stages-compared-held-out-simulated-apps)).
- **hold budget**: the longest GenClass may hold a response, message or request in guard and heal while the model
  decides (`policy.holdBudgetMs`, by default 1.5 times the model's recent median latency, between 150 and 800 ms).
  Observe holds nothing.
- **late revert**: in guard and heal, a state write that already applied and that the model then answers `discard`
  for is reverted, but only within 800 ms of applying (`LATE_REVERT_MS`), if nothing has overwritten it and its
  operation has written nothing else since. It is reported as such and can be undone.
- **local or private host**: a page host where the default telemetry stays off and `?genclass=` or
  `localStorage.genclass` may raise the mode: `localhost` and `*.localhost`, `*.local`, `*.test`, `*.internal`,
  `*.home.arpa`, single-label intranet names, loopback, private, link-local, CGNAT and 0/8 addresses, and an empty
  host name such as a `file:` page's (`isLocalHost` in `src/telemetry/config.ts`;
  [THREAT-MODEL.md T8](THREAT-MODEL.md#t8-configuration-by-url-storage-and-meta-tags)). An intranet or VPN-only
  production app is on one. The measured visual checks use a narrower set, local development URLs.
- **protected request**: a request matched by `requests.protect` (for example `protectPreset("payments", "auth")`).
  It is observed and reported but never acted on, nor is anything its response causes.
- **measured visual check**: a deterministic measurement of a visual or CSS bug (unreadable text, a broken image, a
  stuck scroll lock, and others) with a documented threshold, reported as kind `"check"`. It is never a model
  finding and never feeds a situation, the gate or the model ([VISUAL.md](VISUAL.md)). One indirect path remains: a
  check's read that makes the browser lay out a very heavy page can cause a long task, which the runtime's `perf`
  observer records as an event the model can read (VISUAL.md section 1).
- **flow expectation**: an opt-in, deterministic report that a step a user action usually causes (a request, a
  write, a navigation) did not happen this time ([EXPECTATIONS.md](EXPECTATIONS.md)). The model is not consulted.
- **Jev**: the name of TypeSafe AI's typed-decision API, which GenClass is not affiliated with. The GenClass model
  reads questions in the same request shape (`noul`, `choice` and `score` questions over a state), from the
  project's earlier research in `research/`.
