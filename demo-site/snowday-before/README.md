# Snow Day Predictor, demo copy

A copy of [MeharPro/snowday-predictor](https://github.com/MeharPro/snowday-predictor) (MIT, see LICENSE) as of commit 5828d79,
before GenClass was added, for the GenClass demo (`../DEMO-SCRIPT.md`). Five bugs are planted on purpose: the board
search race, the double Subscribe, the white-on-white alert bar, the scroll lock the notice leaves, the click block
"Load road conditions" leaves. `functions/api/` serves the board search, alerts and road conditions on Cloudflare
Pages. AdSense is removed and every page is noindex: this copy must never compete with or earn for the real site.
